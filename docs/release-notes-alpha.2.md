# v0.1.0-alpha.2 — 短词更自然，0 键可切换

这是诗Emoji的第二个 Alpha 试用版。运行时仍是本地 Lua 与静态词库，不加载模型或联网；输入法原候选顺序、空格和 Tab 行为保持不变。

相对 alpha.1：

- 放开 32 个逐词审定的明确双字联想，例如「上班→💼」「地铁→🚇」；较弱的双字联想仍要求更长候选，单字保持严格策略。
- 补充「歪嘴笑→😏」等明确别名，并加入可重复运行的 Emoji 反查审计。词法有入口不代表单独输入可达；首轮发现 44 个基础 Emoji 暂无可达的孤立映射词条，尚未批量放开。
- 可选 `0` 键实验默认提交「原文 + 空格 + Emoji」，例如 `虾仁 🦐 🍤`。在鼠须管选单可切为「仅Emoji」，之后按 `0` 提交 `🦐 🍤`；切换状态按账号保存。此实验仍需手动启用，并会接管宿主方案命中时的 `0` 键。
- 重口联想默认开启；如不需要，在当前方案配置中设 `shi_emoji/adult: false` 并重新部署。诗Emoji总开关关闭或英文模式下不会查询它。

从本 Release 下载 `rime-shi-emoji-runtime.zip` 与 `SHA256SUMS`；摘要用于检查下载完整性，不是签名。按[安装／升级指南](https://github.com/YebaiZhao/rime-shi-emoji/blob/v0.1.0-alpha.2/INSTALL.md)合并配置，尤其注意 `0` 键实验新增的菜单开关。不要覆盖个人词库或整个 Rime 用户目录。

主要验证环境为 macOS 鼠须管 + 万象全拼；工程回归与隔离原生测试不等于任意中文的语义准确率、长期性能或其他前端的兼容性保证。欢迎提交已脱敏的拼音、实际候选和期望表情。
