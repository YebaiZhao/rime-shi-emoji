# 实验功能：跟随高亮的 Emoji 候选

默认安装仍采用高亮候选旁预览、⌥+回车上屏。若想用单个数字键选择 Emoji，可在已有中文方案的 `*.custom.yaml` 的 `patch` 下加入：

```yaml
  "menu/page_size": 7
  "shi_emoji/candidate_slot": true
```

重新部署后，每页最多先显示 6 个原候选；如果其中至少一个完整中文候选有主库联想，再在页末插入诗Emoji候选。原候选不足 6 个时，Emoji 紧随最后一个候选，所以选择键是该项显示的数字，不一定是 `7`。移动高亮时，Emoji 项随当前候选变化；按它的数字键只提交 Emoji，空格仍提交当前普通候选。原有的 ⌥+回车和 ⌃⌥+回车仍可提交“原文＋Emoji”。

这会把页面上限改成 7：万象当前将 `7` 用于声调输入，启用本实验后，`7` 在候选菜单中用于选词；即使诗Emoji关闭或当前页没有联想，第 7 个普通候选也可由 `7` 选择。若当前高亮词没有联想，但同页其他词有，诗Emoji项暂时显示当前词原文，选中它也只提交原文。关闭实验时，删除 `shi_emoji/candidate_slot` 并将 `menu/page_size` 恢复为原值，重新部署。

此模式仍在验证中，默认安装不会启用；它通过 Rime 原生候选实现，不修改鼠须管界面。
