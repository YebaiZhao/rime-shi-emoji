# alpha.4 之后：常用中文入口可达性（第一批）

后续进展：剩余 1,891 项自然中文叫法已逐项审定，现为 1,906／1,906 项，见[全量自然叫法审定与缺口](natural-name-review.md)。以下保留首批记录及其当时统计，不把后续审定误写成首批已完成。

2026-11-06，发布基线为 `v0.1.0-alpha.4`，本地基线提交 `704b959`。本轮完成固定清单的全量工程反查，并修正第一批明确入口。**不等于 1,906 项自然叫法全部人工审定，也不等于所有 Emoji 已经在输入法中实测可达。**

## 分母和证据分层

固定 `data/emoji_inventory.json`：Unicode 16.0，共 3,781 项，排除 1,875 个肤色变体后为 **1,906 个基础 Emoji**。性别和其他 ZWJ 组合仍在基础分母中。报告按 Unicode 清单顺序编号，一项一行，不用抽样代表全量。

反查入口取以下来源的并集：固定 CLDR 名称与关键词、现有合并词库的逆向映射、三档运行时映射（含已有繁体别名），以及本轮逐词审定的 19 个叫法。通用关键词、陌生译名与繁体别名只是发现候选；不能因为收录或匹配成功就认定它是自然、常用或语义正确的入口。不存在于这些来源中的口语叫法仍可能遗漏。

逐项记录位于：

- `data/reachability/alpha4-baseline/`：同一入口集合对 alpha.4 的反查。
- `data/reachability/current/`：修复后的反查；`entries.tsv` 可直接查看完整 1,906 项和各档入口，`entries.jsonl.gz` 保存逐词逐层结果，`summary.json` 保存分母、计数和输入 SHA-256。
- `data/common_entry_reviews.json`：19 个叫法的自然性理由、拼音及“加入／因边界影响暂缓”的决定。本轮按日常使用场景判断优先级，没有用户词频测量。
- `data/reachability/native-first-batch.json`：19 个词在隔离万象配置中的候选页、选择按键、预览和提交原始结果。

| 层 | 本轮证据及限制 |
|---|---|
| 自然叫法 | 19 个词、15 个 Emoji 有本轮逐词判断；其余 **1,891 个 Emoji** 明确标为 `unverified`。既有 CLDR 名称和映射不是本轮自然性审定。 |
| 词库收录 | 所有候选词分别记录旧合并词库与 alpha.4 三档表是否有精确目标关系；两个布尔值独立。补丁仅进入三档表。 |
| Lua 实际匹配 | 对所有发现词逐个执行真正的 `filter.suffix`，检查严格、一般、发散三档最终输出；默认肤色、中性性别、关闭重口。不是 Python 旧匹配器的前六名。 |
| 拼音候选 | 只实测上述 19 词，使用隔离万象配置、无用户词库，逐页搜索最多 5 页。未找到只表示该输入序列在该页数内未见精确候选，不代表所有输入方法均不可达。其余词标未验证。 |
| 原生预览／提交 | 调用 Squirrel 所带 librime 和 Lua 插件，读取高亮候选注释并用 `Alt+0` 取得原生提交文本。只对找到精确候选的词验证，严格档；不借用 Lua 层结果填补原生证据。 |
| 前端界面／应用插入 | 全部标未验证。无头 C-API 提交不等于鼠须管屏幕呈现或文字已插入某个应用。 |

目标比较按完整输出单元，并仅忽略 VS16；`👩‍🌾` 不算 `👩` 可达，`🐂🍺` 不算独立 `🐂` 可达。不以 Unicode 子串误报覆盖。

## 第一批修正及暂缓项

12 个入口加入严格档，均仅允许完整候选：

| 入口 | 新增目标 |
|---|---|
| 圆圈、红圈、空心圆、空心圆圈 | ⭕ |
| 点头 | 🙂‍↕️ |
| 暂停 | ⏸️ |
| 停止 | ⏹️ |
| 无限大、无穷 | ♾️ |
| 比耶 | ✌️ |
| 粉心 | 🩷 |
| 滑雪板 | 🎿 |

保留已有关系及其档位、句中授权。例如一般档的「红圈」输出 `⭕ 🔴`，「滑雪板」输出 `🎿 🏂`。圆圈原有彩色实心圆关系仍保留；最终组合仍受原有单概念最多两个 Emoji 的限制，新增空心圈优先占一个位置。

7 个自然叫法已审定但**暂缓导出**：红色圆圈、爱心眼、星星眼、浅蓝心、灰色爱心、尖叫猫、女农民。现有运行时会自动把新增的完整词加入保护词，这会屏蔽句中的红色、爱心、星星、蓝心、尖叫／猫、农民等旧子词。为保持本轮句中行为不变，没有修改保护算法，也没有悄悄接受这一副作用。这些项保留在逐项缺口报告中。

导出器使用独立补充清单，不改写此前 11,937 条核心关系审定记录，不替旧记录补填运行时验证。新增关系不会扩大到句中，不改匹配、组合、性别转换或发散算法。

两个阶段均执行 12,518 个不同词、19,453 个词—Emoji 组合；每阶段 37,554 次真实 Lua 调用（三档各一次）。

|---|---:|---:|
| 基础 Emoji 已完成反查 | 1,906 | 1,906 |

严格档不负责接受所有情绪联想，64 项不能直接当作 64 个需要升档的错误。所有“无入口”均限定在本轮枚举词集合与默认偏好下。

一般／发散档仍为零的 5 项：

| Emoji | 观察到的现象／下一步 |
|---|---|
| 🙀 | 固定名称“疲倦的猫”实际输出普通猫，其他情绪词被别的表情占据；“尖叫猫”已审定，因句中边界影响暂缓。 |
| 👵 | 奶奶、老奶奶等实际输出中性老人 🧓，涉及现有性别转换策略；本轮不改。 |
| 👩‍🌾 | 农妇实际输出中性农民 🧑‍🌾；明确“女农民”入口因边界影响暂缓。 |

不要与旧 `reverse_audit` 的“6 个零可达”直接比较：旧工具测的是 Python 旧匹配器，本轮测 alpha.4 的三档最终 Lua 输出，零项集合也不同。

19 词中有 14 词找到精确中文候选；最终加入的 12 词中，10 词通过严格档原生预览及提交，空心圆圈、粉心仅通过 Lua 层。其余 7 个暂缓词的实际旧输出也已原样记录，不能算成修正通过。

原生检查结果及剩余拼音缺口以 `native-first-batch.json` 为准：空心圆圈、爱心眼、粉心、浅蓝心、尖叫猫在本次前 5 页内未找到精确候选。不会因此往活动词库强行加词。自然叫法全量审定、剩余词的拼音层、界面预览与应用上屏仍未完成。

## 复现

在源码仓库运行，不需要联网。需要真实 Lua 5.4（本机复用 Squirrel 插件）。以下命令只写仓库报告或临时隔离配置：

```sh
PYTHONPATH=src .venv/bin/python -m shi_emoji.tier_export
PYTHONPATH=src .venv/bin/python -m shi_emoji.reachability \
  --baseline --output data/reachability/alpha4-baseline

# 目录必须尚不存在；现有万象编译产物只读引用，不复制用户词库。
.venv/bin/python scripts/prepare_wanxiang_probe.py \
  --source /Users/yebaizhao/Library/Rime \
  --output /private/tmp/shi-emoji-common-entry-probe \
  --zero-key --no-adult
.venv/bin/python scripts/probe_common_entries.py \
  --profile /private/tmp/shi-emoji-common-entry-probe \
  --output data/reachability/native-first-batch.json
PYTHONPATH=src .venv/bin/python -m shi_emoji.reachability \
  --native data/reachability/native-first-batch.json \
  --output data/reachability/current
PYTHONPATH=src .venv/bin/python -m unittest tests.test_reachability tests.test_tier_export -v
```

没有本机万象时可省略 `--native`，生成纯 Lua 报告；此时原生层必须保持未验证。原生证据绑定当前运行表和叫法清单的 SHA-256，数据改变后拒绝沿用旧证据。源万象编译词库改变也可能改变候选排序，原生记录另附编译资产指纹。

`--baseline` 在临时目录排除本轮补充词，生成原 alpha.4 三档表；本轮核对它与 `704b959` 的运行表逐字节一致，SHA-256 为 `d33b9a2345a8f14fb96352404494b7e61ce90615db95ea0f1c5dae5bc8248478`。它使用当前同一发现词集合反查历史运行表，19 词的自然叫法审定是本轮判断，不是假称历史已有审定。

测试既检查全部首批修正，也检查已有关系与授权保持不变。另对新增保护词的全部既有句中关系做结构检查，并逐词对照嵌入句在修改前后三档输出，防止入口补齐影响句中触发。报告重建测试覆盖整个 1,906 项分母，不把开发回归当作独立语义准确率。
