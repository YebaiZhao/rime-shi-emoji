## 名称与实际可达性分开

本轮没有把这些新名称批量加入三档表，也没有修改活动词库。新审定行均为 `review_only`，不授予严格档、句中触发或发散关联权限。首批 12 个已加入词和 7 个边界暂缓词保持原决定。

全量反查执行 **14,002 个不同发现词、20,980 个词—Emoji 组合、42,006 次真实 Lua 调用**。先前库名、关键词仍参与反查，但只有逐项选中的名称才计入“审定名称”统计。

| 检查口径 | 仍有缺口的 Emoji 数 |
|---|---:|
| 审定名中没有任何精确三档表映射 | 335 |
| 审定名中没有严格档最终输出入口 | 318 |
| 审定名中没有一般档最终输出入口 | 262 |
| 审定名中没有发散档最终输出入口 | 262 |
| 包括所有旧词及发现词后，一般／发散档仍无入口 | 5 |

“无精确映射”与“无最终输出”是独立条件：旧子词可能输出目标，精确关系也可能受档位、组合或性别转换影响。因此不能把这些数字当成同一指标排序，也不能以“所有旧词中有入口”替代“审定自然名能用”。262 项是下一阶段修复自然入口的明确清单，不是本轮未审定的项目。

一般／发散档完全无入口的 5 项仍是 🙀、👵、👩‍🌾、🧞‍♂️、🧞‍♀️。只看全部发现词，严格档零项为 63，比首批记录的 64 少 1：新增探测词“医护人员”发现 🧑‍⚕️ 的既有可达路径；这是检查范围扩大，**不是新增运行时修复**。

拼音候选、原生引擎预览／提交、前端界面及应用插入，本轮均未新增验证，报告明确标未验证。首批 19 词的原生记录仍在原位置，没有复制为新名称的证据。
