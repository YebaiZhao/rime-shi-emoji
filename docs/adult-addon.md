# 重口联想开关

此扩展收录性暗示、暗黑梗和夸张暴力表达，不是内容过滤器。开关控制联想方式，不是把文字或 emoji 本身划分年龄等级。

统一安装包已包含独立的 `adult.lua` 映射文件，无需额外下载或安装。在当前方案的 `.custom.yaml` 中将 `shi_emoji/adult` 设为 `true`，重新部署并重载即可开启；默认 `false`。独立文件是维护边界，不是额外安装步骤。关闭时不加载、不查询；开启后建立的索引可缓存，但再次关闭并重载后不再查询。

开启后，重口联想只在当前高亮候选旁增加独立预览（标注“重口”），不会新增重口候选行；按 ⌃⌥+回车才提交“原文＋重口 Emoji”。即使另行启用实验数字候选槽，该槽仍只使用主库联想。例：“涩涩”可预览 `🍆🍑`，“地狱笑话”可得到 `💀😂`，“血流成河”可得到 `🩸`。

短而歧义大的词只在整条候选恰好等于该词时触发，例如“开车”“开房”“色图”“爆头”；“今天开车去公司”不会因此出现重口预览。较明确的短语可在长句内匹配，如“今晚去开房”“这个地狱笑话太冷了”。

“茄子→🍆”等普通词义不属于这个开关；它不控制其他输入方案、旧模型词条或用户词库自身的联想，不保证全局过滤任何内容。关闭不会删除已提交的文字。

不需要此类联想时关闭开关即可，无需卸载任何文件。
