# 116 个高优先级叫法修正（未发布）

本轮实现此前逐项审定的116个明确问题：43个精确映射缺口及73个短词误拦。具体回归契约在 `tests/fixtures/basic_keywords_116.json`，编号对应本地审定记录；这116词已经参与开发，不是盲测样本。

## 实现边界

- 通过 `data/literal_aliases.json` 逐词声明本义，不批量放开双字模型词。恐龙、花朵、骆驼、比心手势、门票允许多个合理图形。
- 保留其他合理变体：碰杯的🥂/🍻、电池的🔋/🪫、警车的🚓/🚔等，优先排列明确本义。
- 脚和腿加入逐字许可，但只匹配完整单字候选，不在脚本或其他复合词中匹配。
- `short_term_policy.json/suppressed_generic` 排除两个、兩個和表情。这是排除这些精确词条作为联想线索，不是删除用户输入文字；其他具体名称和同句有效词正常匹配。
- 原始模型产物与审核哈希不变；开发诊断中的 `policy_exclusion` 记录排除原因，运行时不包含这些元信息。
- 重建固定jieba名词边界保护；月牙泉不能因新增月牙而输出月亮。运行时仍无模型、分词服务或网络。
- 系统名称资源仅用于本地发现差异；这里提交的是逐词审定的规则及回归例子，未打包系统原始名称/搜索索引。

## 合理差异保留

15条审定为合理的差异均有最终Lua保留检查。例如向上箭头仍为⬆️，不强改为🔝；音符仍为🎵，不强改为🎶；医护、警察、卫兵保留中性人物策略。头晕目眩在原有最终后缀中的🥴/💫仍可表达其含义，不按原始匹配器的候选排序猜最终输出。

## 覆盖统计变化

| 口径 | alpha.3 | 本轮 |
|---|---:|---:|
| 零词法入口 | 0 | 0 |
| 词法入口不足3个 | 445 | 443 |
| 词法入口不足4个 | 652 | 659 |
| 无首选词法入口 | 0 | 1 |
| 孤立词零可达 | 6 | 6 |
| 孤立词可达入口不足3个 | 1,049 | 1,013 |

不足4个的数量净增7：9项从4降为3，2项从3升为4。下降的9项分别删除了不应作为直接本义/触发线索的入口：🐐的绵羊、🍼的婴儿、🎍的盆栽、👡的皮鞋、⚒️的铁镐、🛠️的扳手、♋的螃蟹、‼️的两个、❎的乘号。上升的2项为🫶和🪏。没有为凑覆盖数字补无关词。

💫原先靠流星充当首选入口；本轮流星改用🌠，💫仍可在头晕目眩的最终后缀中出现，因此首选入口计数出现1项缺口，但不是新添零可达。`coverage_budget.json`按上述真实变化更新，并收紧不足3个和无首选入口预算；这些数量不代表准确率。

## 验证口径

本轮本机严格套件通过116项测试、零跳过；这和116个修复词数量恰好相同，但不是同一口径：116词在测试内部逐项循环，原生候选上屏检查覆盖其中20词。便携检查与原生检查不混称GitHub CI，尚未推送运行CI。

- 116词分别检查精确映射、匹配器前六可达以及最终Lua后缀。匹配器原始分数与最终组合的最长完整词优先规则不同，不以原始候选第一位冒充屏幕结果。
- 15项合理差异保留，泛词长句负例，脚/腿单字边界与具体双叹号正例。
- 原生Rime另以20个已知中文候选检查高亮预览和实际提交，使用隔离profile，不读写活动用户词库。
- 全部属于工程与回归证据；不是116词的独立盲测，也不是对所有系统输入法关键词的覆盖保证。尚未部署或发布。
