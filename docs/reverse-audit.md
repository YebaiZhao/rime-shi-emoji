# Emoji 反查：词条存在不等于单独输入可达

2026-11-02 对当前工作树的全量复核，固定 Unicode 16.0 的 1,906 个基础 Emoji。在源码仓库中复现（运行时 ZIP 不包含 Python 源码）：

```sh
PYTHONPATH=src python3 -m shi_emoji.reverse_audit --max-reachable 0 --limit 50
```

脚本从固定来源与当前规则在内存中重建反向词条，再逐个把完整词条输入 Python 匹配器，检查目标 Emoji 是否进入前六候选。繁体自动别名与肤色变体不重复计数；不会写入词库或下载数据。`--max-reachable 1` 可看只有零至一个可达词条的项目。这里的“可达”只指匹配器层的孤立词查询，不能推断拼音方案里该候选是否容易选到、最终 Lua 组合是否显示它，更不能当作语义准确率。

| 口径 | 数量 |
|---|---:|
| 基础 Emoji | 1,906 |
| 完全没有词法入口 | 0 |
| 词法入口少于三个 | 445 |
| 孤立词查询中零个入口可达 | 6 |
| 孤立词查询中少于三个入口可达 | 1,049 |

上一轮有 44 个零可达项目，其已映射词条全部受 `min_context_len` 门槛限制。本轮从中审定了明确的日常名称，又补了四个方向箭头简称，把零可达降至 6；这不是系统输入法覆盖率或语义准确率。词法入口少于三个的数量从 444 变为 445，是因为「培根」不再把 🐖 当作并列本义，宁可保留准确性，也不为凑词条数保留错误映射。

本轮明确放开 `鸭子→🦆`、`蜘蛛→🕷️`、`蘑菇→🍄`、`培根→🥓`、`气球→🎈`、`沙漏→⌛`、`图钉→📌`、`椅子→🪑` 等。此前「培根」首位是 🐖、「气球」首位是 💬、「椅子」首位是 💺；现在逐词固定本义，未批量撤掉双字门槛。`右箭头→➡️` 等方向简称也以明确别名加入。普通文字符号 `→` 不在 Emoji 清单中，仍需另行设计符号层。

剩余 6 个零可达项是 `😶‍🌫️`、`😍`、`😫`、`😩`、`🚡`、`🚠`：情绪词存在多表情歧义，两种缆车共用相似称谓，暂不靠放宽门槛硬凑。后续应做独立样本的系统输入法对照和实际 Rime 候选验证；这里仅是匹配器层反查，不代表用户能按同样方式从拼音候选上屏。
