# v0.1.0-alpha.4 — 三档联想

下载附件 **rime-shi-emoji-runtime.zip**，不需要下载源码或安装 Python。将解压后的 `lua/shi_emoji` 放进 Rime 用户目录的 `lua`，合并两份 YAML 示例，重新部署。旧用户也需要合并新示例里的三档设置，不能只替换 Lua。

- **三档联想**：在 Ctrl + 反引号选单开启「诗Emoji」，切换「诗Emoji一般／诗Emoji严格／诗Emoji发散」。默认一般；严格偏向直接对应，发散增加创意联想。
- **可选的 0 上屏**：按包内说明启用后，高亮带 `〔0→…〕` 预览的候选，按主键区 `0`。在选单切换「原文＋Emoji／仅Emoji」；`⌥+0` 执行相反方式，取代 alpha.3 的 `Shift+0`。本机鼠须管用户实测 `⌥+0` 上屏后未切到英文。
- **词库修正**：补齐或修正 116 个高优先级叫法，减少泛词和词内误触发。

这是预发行版，主要面向 macOS 鼠须管和万象拼音试用。尚未验证所有 Rime 前端、键盘布局和上下文。运行时包不含审定账本、用户词库或模型权重。
