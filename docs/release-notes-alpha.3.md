# v0.1.0-alpha.3 — 基础叫法补齐，候选提示更短

- 四个方向箭头简称及 38 个明确名称经逐词审定；基础 Emoji 的零独立可达项由 44 降至 6。
- 「右箭头」可匹配 ➡️；修正「培根」「气球」「椅子」等本义排序。
- 0 键实验新增 Shift+0：0 按菜单模式输出，Shift+0 输出相反模式，切换菜单时两键对调。⌥+回车保留为 Shift+0 的兼容键，重口组合键不变。
- 高亮提示缩短为「〔0→Emoji〕」，不再显示「原文＋」或 Shift 键提示。
- 109 项本机隔离检查通过，包含原生 Rime 和 ZIP 安装生命周期。

仍为 Alpha：剩余 6 项歧义映射保留限制；尚未完成系统输入法关键词对照或独立语义准确率评测。普通文本箭头 → 不在 Emoji 清单中。本版不更换宿主输入方案，不携带模型或用户词库。

升级：解压运行时 ZIP，覆盖 Rime 用户目录 lua/shi_emoji 的九个 Lua 模块，保留已有 custom YAML 与用户词库；重新部署并重载。已启用 0 键实验的用户无需新增配置；未启用者见 docs/experimental-zero-key.md。
