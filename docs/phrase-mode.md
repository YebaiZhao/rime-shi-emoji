# 常驻候选增强：运行机制与开发

> 阶段性技术记录。当前运行时为八个 Lua 文件，包含偏好与扩展层；后续变化及限制以 [架构](architecture.md) 和 [安装指南](../INSTALL.md) 为准。下文早期覆盖数字不作为发布版指标。

普通用户请看 [安装与使用](../INSTALL.md)。主交互已从一次性模式改为原生菜单持久开关；旧 Ctrl+Shift+E 入口不再使用。

## 组件职责

- `filter.lua`：默认原样转发候选；监听高亮变化，仅对当前完整中文候选匹配并临时追加注释预览，离开时还原原注释。每个同音词独立匹配。可选的[实验候选槽](experimental-candidate-slot.md)改为增加一项只提交 Emoji 的候选。
- `processor.lua`：高亮完整候选且有匹配时，⌥+回车提交主库、⌃⌥+回车提交重口库。Tab 完全交还宿主，不改变万象音节跳转。
- `matcher.lua`：在每个字符位置收集所有命中的短语，包含嵌套与重叠命中，再合并表情。较长短语和原监督规则仍优先，去重后保留前六项用于推荐。
- `data.lua`：由监督词库和经审核的模型产物导出，附数据来源和许可声明。

新增[完整词保护](word-boundaries.md)：先检索离线编译的名词跨度，过滤严格位于完整名词内部的短语；其余嵌套与重叠短语继续参与。保护词也包含在导出的 `data.lua` 中，无运行时分词依赖。

索引在首次启用并实际查询时才建立，同一 Lua 模块内复用；关闭或英文模式不进行词典查询。不宣称切换开关就立即释放全部内存。

## 否定标注

已完全移除“否定后抑制匹配”的行为。分句边界与四字前文窗口仅用于设置 `negated` 标记；否定意图采用 `🙅 + 该意图首选表情`。多意图句子按短语长度优先选择最多三个不重叠、不同意图及首选表情的概念，再按原文顺序组合，每个概念贡献一个首选表情（显式组合如 🐂🍺 保持整体）。单概念保留最多两个备选表情。`万圣节暴走小朋友` 得到 `🎃 🏃 🧒`，不会让“小朋友”内部的“朋友”再占一位。

例：高亮 `我不想去海边` 时预览 `🙅 🏖️`，按 ⌥+回车上屏 `我不想去海边 🙅 🏖️`。转折词截断标注范围，后面的“想玩游戏”不会被前面的“不想”否定。词内本身已表达意图的监督短语，如“不想上班”，保留自身的摸鱼映射。

这仍不是句法解析。双重否定、跨长距离修饰、反讽、多意图取舍和宿主中文识别错误都可能造成不合预期的表情。

## 为什么以前“不够敏感”

本次实际修正的三项限制：

1. 否定直接删除匹配 → 保留匹配并标注 🙅。
2. 最长短语吞掉重叠短语 → 所有终点、所有字符起点都参与检索。
3. 只看第一解释 → 根据当前高亮的完整解释显示匹配预览；例如“吓人”和“虾仁”不共享表情。

没有把不完整的局部中文候选当整句，也没有在无匹配时硬塞表情。词库仍有限，未覆盖同义词可能没有预览。“暴走”和“小朋友”为人工映射，不属于模型生成结果。

## 测试

标准库参考实现和导出：

```sh
PYTHONPATH=src python3 -m shi_emoji.match '我不想去海边'
PYTHONPATH=src python3 -m shi_emoji.export
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

本机 Rime 集成测试需要现成的已编译中文字典和 PyYAML。创建全新隔离目录：

```sh
python scripts/prepare_wanxiang_probe.py --source "$HOME/Library/Rime" --output dist/resident-menu-probe
RIME_PROBE_USER=dist/resident-menu-probe PYTHONPATH=src python -m unittest discover -s tests -v
```

fixture 使用独立 user-data、独立 default 配置与 user.yaml，关闭主翻译器用户词库；原静态资产以只读链接引用。测试不能直接指向活动用户目录。

探针支持 `--option-state off|on|saved`、`--menu-toggle` 和 `--ascii`。原生菜单测试实际打开选单选择诗Emoji，而不是用 API 强行设置后冒充菜单记忆。两次独立进程分别验证开、关状态的保存。用 `--schema luna_pinyin_simp` 可以准备朙月简体 fixture，并给探针传相同 schema。

Lua 适配测试验证高亮变化时只给当前解释显示预览，以及不误用局部候选。原有候选排序、原文空格提交、高亮同音词后按 ⌥+回车确认、Tab 原功能不变、连续输入、Esc、英文模式、组合和否定也在真实引擎中验证。
