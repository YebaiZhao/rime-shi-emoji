# 诗Emoji · Shi Emoji

**正常打中文，顺手带点表情。**

给 Rime / 鼠须管的中文候选添加 Emoji 预览、按需上屏的轻量插件。不是另一套输入法，也不在打字时运行 AI 模型。

[安装](INSTALL.md) · [English](README.en.md) · [工作原理](docs/architecture.md) · [贡献](CONTRIBUTING.md) · [更新记录](CHANGELOG.md)

```text
高亮候选：我不想去海边 〔诗Emoji 🙅 🏖️〕
按 ⌥+回车上屏：我不想去海边 🙅 🏖️
它靠词组匹配与离线整理的联想工作：
牛逼                 → 牛逼 🐂🍺
三文鱼               → 三文鱼 🍣
开发                 → 开发 🧑‍💻
```
## 为什么试试它

- **保留打字习惯**：原候选顺序不变，空格和万象原有的 Tab 行为不变。只有高亮候选显示 Emoji 预览；想带表情时按 ⌥+回车。
- **可选的单键实验**：把跟随高亮的 Emoji 放在当前页普通候选后，按显示的数字键只上屏 Emoji。这会把每页上限设为 7，改变 `7` 的选词／声调用途；没有 Emoji 时普通第 7 候选仍可能出现。见[实验说明](docs/experimental-candidate-slot.md)，默认安装不启用。
- **长句里找线索**：从多个片段组合最多三个概念，不要求整句已经收进词典。
- **全程本地**：运行时只有 Lua 和静态数据，不联网、不加载模型、不依赖后台服务；插件自身不采集打字日志。宿主输入法的日志设置独立于本插件。
- **有偏好，不强迫**：原生选单开关、肤色与性别偏好；重口联想默认关闭，所有文件在同一个安装包里。
- **能追查来源**：正式名称、人工本义、人工联想与模型建议分层决策，不把模型分数当正确率。

## 开始使用

当前准备版本为 **v0.1.0-alpha.1**，优先面向 macOS 鼠须管 + 万象全拼试用。其他前端尚未完成兼容性验收。
发布后从本仓库 Releases 下载 `rime-shi-emoji-runtime.zip`。尚无 Release 时，可从源码用 `python3 scripts/package_runtime.py` 生成同名包。

1. 解压，将 `lua/shi_emoji` 放进 Rime 用户目录的 `lua` 下。
2. 合并包内两个 `.yaml.example` 的配置：中文 schema custom 文件添加组件/开关，`default.custom.yaml` 添加状态保存项。不要覆盖已有配置。
3. 重新部署、重载，在 Ctrl + 反引号选单中切到「诗Emoji开」。

完整配置、升级、卸载和排障见 [安装指南](INSTALL.md)。

开启后：只有当前高亮且命中的完整中文候选显示预览，不新增候选行。移动高亮到想要的词，再按 ⌥+回车上屏「该词 + 主库 Emoji」；普通空格仍提交纯文字。Tab 完全保留原方案功能。开启重口联想后，使用 ⌃⌥+回车提交重口预览。提交或 Esc 不会关闭插件。

## 可以调什么

| 设置 | 可选值 | 初始值 |
|---|---|---|
| 诗Emoji | 关 / 开 | 关 |
| 肤色 | 原色、浅、中浅、中、中深、深 | 原色 |
| 性别 | 中性、女性、男性 | 中性 |
| 重口联想 | 关 / 开 | 关 |

例如女性 + 中肤色可让「开发」得到 `👩🏽‍💻`；「女科学家」这种明确表达不因男性默认值而被改成男性。只选 Unicode 清单中存在的变体，多人混合肤色未统一处理。

重口联想覆盖性暗示、暗黑梗和夸张暴力表达，详见 [偏好与范围](docs/preferences.md)。

## 能力边界，先说在前面

- **不是实时语义模型**：词库有限，歧义、反讽、双重否定和陌生说法仍可能出错。「房地产开发」仍可能误联想到程序员。
- **中文解释由原方案决定**：插件分别匹配每条完整中文候选，不会把首选词的 Emoji 套到其他同音词上。局部候选不会被当成整句匹配。
- **工程测试不是语义盲测**：本机原生 Rime、Lua、安装包和回归检查通过；没有独立总体准确率，也未完成长时间内存与跨平台验收。

## 如何工作

```text
宿主当前高亮候选 → 词组匹配与完整词保护 → 不同概念组合 → 性别/肤色偏好 → 高亮项预览 → ⌥+回车确认
```

模型只在开发阶段帮助提出映射，运行时不参与。词典采用 Unicode CLDR、jieba、人工规则与审核后的模型建议；可用开发命令查看某个词的来源和取舍：

```sh
PYTHONPATH=src python3 -m shi_emoji.match 奶牛 --top-k 20
```

## 一起把它变好

欢迎补充日常叫法、报告误联想、验证其他 Rime 前端。提交前附「拼音输入 / 实际中文候选 / 实际与预期表情」，不要提交私人聊天或用户词库。词义与模型建议必须标明来源；看过并用于调词的例子只算回归集，不再称盲测。

详见 [贡献指南](CONTRIBUTING.md)。项目不自动安装或改写活动 Rime 配置。
